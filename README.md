# Sales Dashboard Starter

Files:
- `streamlit_app.py`: interactive dashboard
- `requirements.txt`: Python dependencies
- `sample_sales.csv`: fictional sample data only

Deploy by uploading these files to GitHub, then creating an app at https://share.streamlit.io/ with main file `streamlit_app.py`.

Important: this starter's uploader previews files only in the current session. Shared persistent publishing, admin-only updates, and automatic OneDrive sync are not implemented yet. Do not use confidential sales data until those are configured.
